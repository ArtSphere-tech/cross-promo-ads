🚀 How to Deploy on GitHub Pages in 3 Minutes
1

Create a New GitHub Repository

Go to github.com/new, name it cross-promo-ads, and make it Public.

2

Upload This Entire Folder

Drag and drop the contents of CrossPromo_GitHubPages (or run bash publish_to_github.sh) and commit changes to main.

3

Turn on GitHub Pages

In your repo, go to Settings → Pages. Under Branch, select main, folder / (root), and click Save.

4

Paste Your Link in Unity

Copy your GitHub Pages link (e.g. https://<username>.github.io/cross-promo-ads) into CrossPromoInitializer.cs in your game projects!
